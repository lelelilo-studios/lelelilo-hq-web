# Lelelilo HQ

An isometric office where every employee is an AI agent drawn as a lelelilo pillow: they read, write code, run
builds, queue at the boss's door when they need you, and take coffee breaks when there is nothing to do.

**Open: https://lelelilo-studios.github.io/lelelilo-hq-web/**

It needs a browser with WebGPU: Chrome or Edge on a computer or an Android phone, or Safari 26 and later.

This repository holds only the published build. A project by [lelelilo.com](https://lelelilo.com/?ref=lelelilo-hq).
